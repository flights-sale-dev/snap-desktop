# flightsSALE Desktop Client (Linux Snap)

[![Official Website](https://img.shields.io/badge/Website-flights--sale.com-blue)](https://flights-sale.com)
[![Snap Store](https://snapcraft.io/flights-sale/badge.svg)](https://snapcraft.io/flights-sale)
[![License](https://img.shields.io/github/license/flights-sale/snap-desktop)](LICENSE)

This is the official open-source repository for the **flightsSALE** Linux Desktop App featured on [flights-sale.com](https://flights-sale.com). 

flightsSALE is an independent flight intelligence engine that curates publicly posted official airline deals, promo codes, and flash sales from around the world in real time.

---

## Key Features

* **Real-Time Deal Briefings**: Distills complex airline announcements into clean, actionable, bite-sized intel briefs.
* **Official Promo Codes & Perks**: Uncovers limited-time promo codes, App-only sales, companion discounts, and official carrier perks.
* **Global Coverage & Auto-Translation**: Tracks regional carrier promotions worldwide and automatically translates them into 10 major languages.
* **100% Verified Sources**: Rigorously verifies official airline channels to ensure legitimate information and protect you from fake offers or phishing.

## Installation

### From Snap Store (Recommended)

You can install `flightsSALE` directly from the Snap Store or via terminal:

```bash
sudo snap install flights-sale
```

Or search for **flightsSALE** in your Linux distribution's Software Center / Snap Store application.

---

## Development & Building from Source

### Prerequisites

* [Node.js](https://nodejs.org/) (v18+)
* [npm](https://www.npmjs.com/)
* [Snapcraft](https://snapcraft.io/docs/snapcraft-overview) (for building `.snap` packages)

### Setup & Run locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/flights-sale/snap-desktop.git
   cd snap-desktop
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start application in development mode**:
   ```bash
   npm start
   ```

4. **Build Snap package locally**:
   ```bash
   snapcraft
   ```
